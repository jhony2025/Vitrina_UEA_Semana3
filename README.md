# Vitrina UEA

## Actualización del Proyecto

En esta actualización se realizaron mejoras en la estructura y presentación de la página web **Vitrina UEA**, manteniendo el contenido original del proyecto y agregando nuevos elementos visuales para mejorar la experiencia del usuario.

## Objetivo de la actualización

Fortalecer la apariencia de la página web mediante la incorporación de imágenes, organización de tarjetas de presentación y mejoras en el código HTML y CSS, preparando el proyecto para futuras funcionalidades.

## Cambios realizados

- Se incorporaron imágenes representativas de tiendas de ropa.
- Se organizó la sección de tiendas destacadas utilizando tarjetas (Cards) de Bootstrap.
- Se corrigieron errores en la estructura del código HTML relacionados con las etiquetas `<img>`.
- Se mejoró la organización del contenido dentro de las tarjetas.
- Se añadieron descripciones para cada tienda.
- Se ajustó el diseño para mantener una presentación más ordenada.
- Se realizaron pruebas de funcionamiento para verificar la correcta visualización de las imágenes.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Estado actual

Actualmente el proyecto cuenta con una interfaz funcional que presenta información de la plataforma, secciones informativas, formulario de registro de productos, imágenes de tiendas y un diseño adaptable mediante Bootstrap.

## Próximas mejoras

En las siguientes versiones se tiene previsto implementar:

- Diseño moderno con una apariencia similar a aplicaciones comerciales.
- Buscador de productos.
- Catálogo dinámico.
- Chat entre compradores y vendedores.
- Panel de administración para tiendas.
- Integración con base de datos.
- Sistema de autenticación de usuarios.
- Optimización para dispositivos móviles.
